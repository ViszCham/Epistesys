The baseline is a fixed source snapshot of Labyrinth-Codex v6.3.1. The source revision observed at capture is `4aa84b8ddba80add1d5807413684a27d1356c6fa`; the selected plugin subtree contains 123 files; and the source-package identity is `6.3.1+codex.20260828004025`. This record is not the final Epistesys identity. EPI-04 will align the clone to `Epistesys 6.3.2-alpha.1` and re-check source and distribution binary separately. Original Git history, remote settings, personal state, caches, credentials, receipt roots, and replay ledgers are outside the baseline.

The baseline is a comparison target for observed implementation states, including accept, reject, Unavailable, Hold, Clarify, and fallback. Source revision, binary hash, schemas, fixtures, main commands, toolchain, features, and targets will be tracked in the post-migration clone report. This is not a guarantee of v6.3.1 correctness, general performance, formal proof, host-level enforcement, or external-backend readiness.
