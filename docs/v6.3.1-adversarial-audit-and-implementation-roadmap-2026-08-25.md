6. Unknown、Incomparable、Absent、Deny、Conflict、Unavailableを潰さない。
7. schema ready、runtime observed、decision contributing、fault contained、host boundを別々に記録する。

## English

### Boundary

v6.3.1 is an independent shadow line that does not modify the root v6.3.0 implementation. During development it uses only `6.3.1-alpha.*` and `lc631-*`, and makes no claim of automatic activation, host interception, mutation authority, truth, proof, or general GPU acceleration.

### Frozen baseline

| Surface | Value |
| --- | --- |
| v6.3.0 commit | `0d933982fa392043c2fe825644a3a560963b6615` |
| root plugin manifest SHA-256 | `172961d5f06f1d8ccd395133e1a67ccf5c230e874be4a100abfbe1e5199e0362` |
| root Cargo.toml SHA-256 | `0ae97c5556baab8b1e80967877c37b13632bfb42d1cc50a40649a5baaf680fac` |
| root Cargo.lock SHA-256 | `261b3653b855e0dcf76ac8c977c2ec6ae85372b8a63b6a04e6267a171dac2823` |

### Invariants

1. Build at most 2,048 evaluations from 256 distinct worlds and eight projections; reprojection replaces generation slots.
2. Canonical TranslationLoss uses ProjectionWitnesses and defect sets; fixed weights or means do not decide hard gates.
3. Only AcceleratorBroker may mint an ExecutionReceipt.
4. GPU execution creates no Authority, Evidence provenance, semantic truth, or OutputCommit.
5. A YouTube URL without source authority cannot yield media bytes.
6. Unknown, Incomparable, Absent, Deny, Conflict, and Unavailable remain distinct.
7. Schema readiness, runtime observation, decision contribution, fault containment, and host binding are recorded separately.
