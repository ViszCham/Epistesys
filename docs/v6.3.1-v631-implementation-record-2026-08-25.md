- CUDA ASR observed a missing `cublas64_12.dll` and fell back to CPU int8. Transcript and diarization accuracy are limited observations over a two-speaker fixture.
- Automatic host-output callback and persistent supervision through a trusted Codex `Stop` hook were observed. Remote-client delivery completion, user authority, and semantic truth remain unobserved.
- A 64-seed pass is a fixed-corpus structural regression, not universal semantic equivalence or answer quality.
- Parallel package installation and fresh-host pickup were observed while v6.3.0 remained enabled. Remote CI is a per-commit external receipt and is not promoted to success from static prose alone.
